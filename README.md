# Nouva Market (نوفا ماركت)

المنصة الرائدة للتسويق بالعمولة وإدارة الموردين والبائعين في الجزائر.

## 🚀 المميزات الأساسية:
- **نظام التحقق الصارم الدخول:** حماية كاملة لحسابات الموردين والبائعين.
- **عزل الحسابات والمحافظ المالية:** حسابات منفصلة ومستقلة لكل مستخدم.
- **إدارة الطلبيات والمخزون:** تتبع الشحنات والعمولات ونسب الأرباح.
- **دعم الفانيكون واللوغو الجديد:** هؤية بصرية خضراء ثلاثية الأبعاد.
